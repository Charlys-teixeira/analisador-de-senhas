# 🔐 Analisador de Senhas

Projeto desenvolvido em Python com o objetivo de avaliar a força de uma senha.

## 🚀 Funcionalidades

- Verifica tamanho da senha
- Identifica presença de números, letras maiúsculas e símbolos
- Detecta padrões inseguros:
  - repetição de caracteres
  - sequência numérica
- Classifica a senha como:
  - fraca
  - média
  - forte
- Exibe os motivos da classificação

## 🛠 Tecnologias

- Python
